# Architekt Portfolio Website

This is a single page portfolio page built using React.js

## Running the project
- Run `npm install` to install npm packages
- Run `npm start` to start a development server
- Run `npm run build` to build the project

## Project structure
* `src/components/common/`: Reusable, stateless structural UI pieces.
* `src/components/layout/`: Reusable layouts.
* `src/components/sections/`: Feature-specific modular components.
* `src/assets/`: Custom images and icons.
* `src/data/`: Static data for the UI
* `src/theme/`: Theme for the UI
